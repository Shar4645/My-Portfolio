Selected projects

DocuMind

RAG · Document Q&A

A Retrieval Augmented Generation assistant that answers natural-language questions over private PDF sets. Documents are chunked and embedded into a FAISS vector store; a FastAPI backend retrieves the relevant passages, passes them to the model, and returns an answer with its source citations — so every claim can be traced back to a page. The API, vector store and interface run as separate services under Docker Compose, so the whole stack comes up with one command.

Automated Image Caption Generator

Deep learning · Vision

An image captioning system built on a CNN and Transformer encoder–decoder architecture, generating natural-language descriptions for input images. Predictions are served two ways: a Streamlit interface for interactive use, and a REST endpoint for programmatic calls. The model and application are containerized with Docker, so inference runs identically on any machine.
