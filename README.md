# Portfolio — Tarun Sharma

Personal portfolio site of **Tarun Sharma**, AI Engineer working on Generative AI
and Large Language Model systems in Python, Docker and FastAPI.

**Live site:** https://shar4645.github.io

## About

Single-page portfolio covering my experience at Ethara AI, selected projects,
technical skills, education and contact details.

## Built with

- Plain HTML and CSS — no framework, no build step
- Vanilla JavaScript for the interactive canvas, theme toggle and scroll progress
- HTML canvas for the animated latent-space field in the hero
- Inline SVG for the project architecture diagrams
- Google Fonts: Sora, Manrope, JetBrains Mono

Everything is in a single `index.html`, including the portrait as an embedded
base64 image — one file, no external assets.

## Features

- Day and night themes, remembered per visitor, following the system setting by default
- Responsive from phone width upward
- Respects `prefers-reduced-motion` — all animation falls back to a static state
- Hosted free on GitHub Pages

## Running locally

Clone the repository and open `index.html` in a browser. There is nothing to install.

```bash
git clone https://github.com/Shar4645/shar4645.github.io.git
cd shar4645.github.io
open index.html
```
